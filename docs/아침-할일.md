# 일어나서 할 일 (2026-11-08)

## ① PC 터미널 (VS Code, 순서대로)
1. git checkout -- functions/package-lock.json package-lock.json
2. git pull origin main
3. npm ci --prefix functions
4. 비밀값 (없으면 서버 배포 실패)
   - firebase functions:secrets:access ANTHROPIC_API_KEY   (값이 안 나오면 ↓)
   - firebase functions:secrets:set ANTHROPIC_API_KEY
   - firebase functions:secrets:set DATA_GO_KR_KEY        (키가 아직 없으면 none)
   - firebase functions:secrets:set UPLOAD_TOKEN_SECRET   (아무 영문·숫자 40자 이상)
5. firebase deploy --only firestore:indexes        ("삭제?" → N)
6. firebase deploy --only functions                ("삭제?" → N, 10~20분)
7. 관리센터 › 운송사 분리 › [로그인 토큰 권한 채우기] 실행
8. 20분 기다린 뒤: firebase deploy --only firestore:rules,storage
9. (첨부 미리보기가 안 되면) gcloud storage buckets update gs://dispatch-app-9b92f.firebasestorage.app --cors-file=storage-cors.json
