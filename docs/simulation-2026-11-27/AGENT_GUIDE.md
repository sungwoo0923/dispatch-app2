# 테스트운송사 실무 시뮬레이션 — 에이전트 공통 가이드

운영 중인 실제 서비스 https://app.logisweb.co.kr 의 **테스트운송사**(회사코드 (회사코드))에서 실무자처럼 일해 보고,
오류 · 끊긴 연동 · 실무자 입장에서 불편한 점 · 개선 아이디어를 찾는다. 소스는 /home/user/dispatch-app2 (React+Firebase, 읽기 전용으로만 참고).

(G 모바일 담당만 예외: 모바일 화면으로 다른 계정에 들어가도 PC 세션은 안 끊긴다.)
승인 대기로 남은 계정(시뮬테스트 · 한인사 · 윤인사 · 서영업 · 문법무)은 요금제 인원 한도 때문에 승인하지 않는다.

## 브라우저 헬퍼 — `sim/lw.js`
```js
// 실행: cd <sim 폴더> && NODE_PATH=$(npm root -g) node myscript.js
const lw = require('./lw');
const { ctx, p } = await lw.open('아무이름', 'lwsim.tmgr@example.com', '(테스트 비밀번호)'); // 로그인까지(20~40초). { mobile: true } = iPhone 화면
await lw.go(p, '배차관리');        // 상단/왼쪽 메뉴나 화면 글자 클릭(정확히 일치하는 글자) + 팝업 닫기
await lw.tap(p.getByText('저장'));  // 화면 배율 때문에 일반 click 이 "outside of viewport" 로 막힐 때 DOM 클릭
console.log(await lw.text(p, 8000)); await p.screenshot({ path: 'b_01.png' });
console.log(p.__errs.join('\n'));   // 페이지 오류 · 콘솔 에러 · 브라우저 alert 내용
await lw.close(ctx);
```
- 매 실행마다 새로 로그인한다(프로필 재사용 시 부팅 화면에서 멈춤 — 쓰지 말 것).
- 앱 안의 확인창(kpConfirm)은 브라우저 dialog 가 아니다: **Enter = 확인, Escape = 취소**. 확인창 문구를 먼저 읽고 누를 것.
- 커스텀 드롭다운은 버튼 → 옵션 글자 클릭 방식.
- 지도/주소검색 일부 외부 호스트(apis.openapi.sk.com, cdn.jsdelivr.net, daumcdn)는 이 환경에서 막혀 있다 — 그 때문에 생기는 오류는 버그로 보고하지 말고 "환경 제약"으로만 적는다.
- 스크린샷은 자기 폴더 `sim/shots/<에이전트글자>/` 에. 직접 보고 판단할 땐 Read 로 이미지를 열어 본다.
- 스크립트는 짧게 여러 번 — 한 번에 한 화면/한 동작씩 확인하며 진행.

## 데이터 규칙
- 내가 만드는 데이터(오더 · 거래처 · 기사 · 전표 · 결재 등)는 이름이나 메모에 **`[시뮬]`** 을 붙인다. 예) 거래처 `[시뮬]한빛물산`, 기사 `[시뮬]홍길동`, 차량번호 `서울99사9001` 처럼 가짜.
- 날짜는 2026-11-27(오늘) 전후, 금액은 현실적으로(예: 25만원, 부가세 별도).

## 절대 하지 말 것 (실제 외부로 나가거나 되돌릴 수 없는 일)
- 세금계산서 **발행**(팝빌/국세청 전송), 문자 · 카카오 알림톡 · 이메일 **실제 발송**, 계좌이체 · 결제 · 요금제 변경 · 추가 계정 신청
- 회사 초기화 · 전체 삭제 · 데이터 일괄 삭제, 남이 만든(시뮬 아닌) 데이터 수정/삭제, 다른 직원 권한 · 승인 변경, 비밀번호 변경, 2차 인증 켜기
- 발송/발행 버튼 앞까지 가서 화면 · 미리보기 · 확인창 문구까지만 확인하고 Escape 로 취소.
- 소스코드(/home/user/dispatch-app2)는 **읽기만** 한다. 수정 · 커밋 금지.

## 보고서 — `sim/findings/<에이전트글자>.md`
진행하면서 바로바로 덧붙여 쓴다(중간에 끊겨도 남도록). 항목마다:
```
### [분류] 한 줄 제목
- 분류: 오류 | 연동끊김 | 불편 | 개선아이디어 | 확인됨(정상)
- 중요도: 높음 | 보통 | 낮음
- 계정/화면: 김운송(운송관리자) › 배차관리 › 오더 등록
- 재현: 무엇을 눌렀더니 → 무슨 일이 생겼는지 (실제 문구 그대로)
- 기대: 실무자라면 이렇게 돼야
- 근거: 스크린샷 경로, 관련 소스 위치(파일:줄) 있으면
```
마지막에 "## 요약" — 가장 중요한 5개와 실무자 한 줄 소감.
최종 답변(내게 돌려줄 글)은 요약 + 보고서 경로만 짧게.
