### [오류] 경영 HOME '올해 누적 매출 5,854만원' vs 내륙 HOME '올해 매출 5,667만원' — 187만원 차이(같은 시각, 같은 기준 문구)

- 재현(14:25~14:27): 경영 HOME 이번 달 339만원 · 올해 누적 5,854만원(이익 742만원). 내륙 HOME 이번 달 339만원(같음) · 올해 5,667만원(누적 162건 · 수익 715만). 경영 분석 손익 '최근 12개월 매출 5,327만원'(11월 제외, 25년 11~26년 4월은 0) + 이번 달 339만 = 5,666만 → **내륙 HOME · 경영 분석은 서로 맞고 경영 HOME만 187만원 많음**. 이번 달은 둘 다 339만이므로 차이는 1~10월(지난 기간 pastCache) 쪽.

- 기대: 세 화면(경영 HOME · 내륙 HOME · 경영 분석) · 매출관리 연 누계가 같은 함수로 같은 값.

결재 흐름: E 3건(휴가 → 전무 승인 → 대표 승인 = 결재 완료 / 입사일 기안 → 전무 승인 → 대표 반려 / 소모품 지출결의 → 전무 반려 = 즉시 반려) + 대표 직접 기안(DG-20261127-IUKR → 전무 승인 = 완료) 모두 정상. 반려 사유 필수 · 결재자 없는 상신 차단 정상.
참고: 마스터(테스트계정) 로그인은 2회(결재 1단계 처리 · 관리자메뉴 보기), 각 3~4분. 권한 · 로그인 관리는 보기만 했고 변경 없음.

실무자(대표) 한 줄 소감: "경영 브리핑 화면은 예쁘고 정보도 많은데, 같은 화면에 매출이 세 개(588 · 499 · 452)라 '그래서 이번 달 매출이 얼마냐'를 물으면 답할 수가 없고, 정작 매출관리 화면은 들어갈 수도 없다."
