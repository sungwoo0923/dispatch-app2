# LogisWeb 홍보 기준표 (사람 · 자동화 공용)

> 블로그 · 영상 · SNS 글을 쓸 때 **이 파일에 있는 사실만** 씁니다. 관리자센터 › 홍보 › 홍보 설정 › 홍보 기준표에서 고친 내용이 있으면 그쪽이 먼저 쓰여요(AI 원고 · 매주 자동 초안).
> 기능이 바뀌면 이 파일부터 고쳐 주세요.

## 한 줄 소개
- 로지스웹(LogisWeb)은 화물 운송사를 위한 통합 운송관리시스템(TMS)이에요.
- 슬로건: **배차부터 정산까지, 운송사 업무를 한 화면에서**
- 만든 사람: 배차 실무 10년 현직 배차팀장이 설계부터 직접 참여

## 누구를 위한 프로그램인가 (타깃)
- 1차: 직원 3~25명 규모 화물 운송사 · 주선사의 **배차팀장 / 대표**
- 2차: 경리 · 정산 담당, 지입차를 운영하는 운송사
- 고민: 카톡 오더 수기 입력, 중복 배차 · 누락, 기사 위치 확인 전화, 인수증 사진 전달, 월말 엑셀 정산, 흩어진 매출 데이터

## 핵심 기능 (사실)
| 기능 | 설명 |
|---|---|
| 오더 스캔 | 카톡 · 문자 글이나 캡처 이미지를 붙여넣으면 상하차지 · 일시 · 차종 · 화물 · 운임 등 항목을 자동 인식(글 약 20개 항목, 이미지 19개 항목 예시). 여러 건도 오더별로 분리. 적용 전 검토 후 저장 |
| 실시간배차현황 | 전일 · 당일 · 익일 오더를 한 보드에서. 여러 담당자가 동시에 작업해도 실시간 동기화. 청구운임 · 기사운임 · 수수료 합계 실시간 집계, 미배차 · 긴급 팝업 |
| 배차 등록 | 거래처 선택 시 상하차지 · 담당자 자동, 기사 선택 시 차량번호 · 연락처 자동. 오더 복사 · 정기오더 · 다중 등록, 적재 계산기, 변경 이력 |
| 운임 조회 | 실거래 운임 이력으로 구간별 최저 · 평균 · 최고 운임, 전국 운임 조회, 단가표 발행 |
| 실시간 관제 | 기사앱이 GPS 위치를 백그라운드 전송(화면 꺼져도). 지오펜스(상하차지 반경) 진입 시 상차 · 하차 자동 전환. 지연 · 긴급 알림 |
| 기사앱 | 오늘 오더 · 길안내 · 사진(인수증) 업로드 · 운행기록 · 서류함 · SOS. 일반 기사 무료 · 무제한 |
| 정산 | 배차 운임이 거래처 청구 · 기사 지급 · 회계 장부로 자동 연결. 거래명세서 PDF · 엑셀 · 메일, 지입 기사 지급명세서 일괄 산출 · 기사앱 일괄 발송, 대량이체 파일, 월 마감 점검 |
| 매출 · 경영 | 매출 대시보드(일별 · 월말 예상 · 매익률), 거래처 · 담당자 분석, 월간 경영 보고서 |
