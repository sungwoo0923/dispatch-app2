# 숏츠 01 · Canva에서 소리 입히기 (음성 + 배경음 + 효과음)

영상: `out/01-카톡오더-한줄등록.mp4` (40.4초, 1080×1920)
아래 초는 영상에서 직접 잰 장면 전환 시점이에요. 나레이션 길이는 장면에 맞춰 줄였어요.

## 0. 준비
1. Canva 첫 화면 → **디자인 만들기 → 모바일 동영상(1080×1920)**
2. 왼쪽 **업로드 항목 → 파일 업로드** → mp4 선택 → 페이지에 넣고 화면 꽉 차게 맞춰요
3. 타임라인에서 페이지 길이를 영상 길이(40.4초)에 맞춰요

## 1. AI 음성 (타임라인 **오디오 추가 → AI 음성 생성** · 언어 **한국어**)
목소리: **30대 남성, 차분하고 또렷한 톤**(없으면 여성 차분한 톤). 속도는 기본이나 1.1배로 해요.
문장마다 **따로 만들어서** 아래 시작 초에 맞춰 놓아요. 한 번에 다 만들면 장면이랑 안 맞아요.

| # | 시작 | 장면(길이) | 넣을 문장 |
|---|---|---|---|
| 1 | 0.3초 | 카톡 오더 (4.5초) | 카톡 오더, 아직도 칸칸이 옮겨 치세요? |
| 2 | 5.0초 | 빠른 등록 (7초) | 문자 한 줄 그대로 붙여넣으면, 상하차지, 톤수, 차종, 운임까지 알아서 들어가요. |
| 3 | 12.3초 | 지난 노선 (7.3초) | 자주 뛰는 노선은 지난 오더에서 찾아와요. 엔터 한 번이면, 오더 입력 끝. |
| 4 | 19.9초 | 수수료 계산 (7.3초) | 기사운임만 넣으면 수수료가 바로 계산돼요. 계산기 두드릴 일 없어요. |
| 5 | 27.5초 | 배차판 (5.6초) | 오늘 청구, 기사운임, 마진까지. 배차판에서 한눈에. |
| 6 | 33.3초 | 기사 알림 (3.4초) | 기사님 수락, 거절도 바로 알림으로. |
| 7 | 37.0초 | 엔드카드 (3.4초) | 배차부터 정산까지, 로지스웹. |

- 문장이 장면보다 길게 나오면 속도를 1.1~1.2배로 올리거나, 쉼표를 빼요.
- 읽는 법을 틀리면 이렇게 바꿔 적어요: "5톤 윙" → "오톤 윙", "35만" → "삼십오만".

## 2. 배경음 (오디오 추가 → **음악**)
**Canva 검색어**(이 순서로 찾아보세요)
1. `corporate tech upbeat`
2. `business technology`
3. `minimal electronic`
4. `lofi hip hop`(조금 편한 분위기로 갈 때)

**고르는 기준**
- 가사 없는 곡
- 빠르기는 중간쯤(BPM 100~120). 너무 신나면 업무 프로그램 느낌이 안 나요
- 첫 1초부터 바로 소리가 나는 곡. 앞부분이 조용히 시작하면 그 부분을 잘라 내요
- 밝은 신스·피아노·가벼운 비트. 웅장한 오케스트라나 EDM 드롭은 피해요

**설정**
- 볼륨 **15~20%**(음성이 또렷하게 들리게)
- 끝 **1초 페이드아웃**
- 길이는 40.4초에 맞춰 잘라요

## 3. 효과음 (오디오 추가 → 검색) · 있으면 확 살아나요
| 시점 | 검색어 | 용도 |
|---|---|---|
| 0.3초 | `message notification` / `pop` | 카톡이 도착하는 순간 |
| 약 6~9초 | `keyboard typing` | 빠른 등록에 글자 입력 (화면에서 타자가 끝나는 시점에 맞춰 잘라요) |
| 약 10.5초 | `click` / `soft pop` | 노란 박스 강조 |
| 약 15.5초 | `click` | 엔터로 노선 채우기 |
| 약 21~22초 | `keyboard typing`(짧게) | 기사운임 300000 입력 |
| 33.3초 | `notification ding` | 기사 수락 알림 |
| 각 STEP 전환(4.8 · 12.0 · 19.6 · 27.2 · 33.1초) | `swoosh` / `whoosh`(작게) | 화면 전환 |

효과음 볼륨은 **30~40%**로 해요. 너무 크면 음성을 덮어요.

## 4. 내보내기
**공유 → 다운로드 → MP4 동영상 → 1080p** → 유튜브 숏츠에 올려요.
제목·설명·태그는 `SCRIPTS.md` 01번에 있어요.
