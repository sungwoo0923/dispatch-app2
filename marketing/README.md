## 1. 전략 한 장 요약

**누구에게**: 직원 3~25명 운송사 · 주선사의 배차팀장과 대표.
**무엇을**: "내 일이 줄어든다"는 장면 하나. 기능을 늘어놓지 않고, 매일 겪는 불편 1개 → 로지스웹 화면 1개로 끝내요.

| 매일 겪는 불편 | 보여 줄 화면 | 콘텐츠 |
|---|---|---|
| 카톡 오더 손으로 옮겨 적기 | 오더 스캔 | 숏츠 ① · 블로그 1편 |
| "기사님 어디세요?" 전화 | 실시간 관제 · 기사앱 | 숏츠 ② · 블로그 2편 |
| 월말 엑셀 정산 | 지입정산 · 전자결재 | 숏츠 ③ · 블로그 3편 |
| 엑셀로 버티는 중 | 전체 흐름 | 예고편 · 블로그 4편 |

**흐름**: 숏츠(처음 알게 됨) → 블로그 · 예고편(믿게 됨) → 홈페이지 무료 체험 신청(행동).
모든 링크는 `logisweb.co.kr`, 끝에는 항상 **"무료 체험 신청"** 한 가지만 요청해요.

**강점(다른 프로그램과 다른 점)**: "현직 배차팀장이 직접 만든 프로그램". 대표님 · 팀장님 얼굴이 나오는 영상이 가장 강해요(아래 6장 아이디어).

## 4. 블로그 올리는 법

블로그는 **두 군데**에 올라가요.

### ① 홈페이지 블로그 (자동) — `logisweb.co.kr/blog`
- 이 작업이 main에 합쳐지면 첫 글이 바로 올라가요. 나머지 3편은 날짜(11/30 · 12/7 · 12/14)가 되면 자동 게시돼요.
- 구글 · 네이버가 우리 도메인 글을 읽어 가서 "배차프로그램" 같은 검색에 홈페이지가 잡히게 해 줘요.
- **네이버 서치어드바이저**(searchadvisor.naver.com) → 사이트 관리 → 요청 → **RSS 제출**에 `https://www.logisweb.co.kr/blog/rss.xml`, **사이트맵 제출**에 `https://www.logisweb.co.kr/sitemap.xml` 을 한 번만 넣어 두면 새 글을 알아서 가져가요. 구글 서치 콘솔에도 사이트맵을 넣어 주세요.

### ② 네이버 블로그 (손으로 5분)
네이버는 블로그 자동 글쓰기 공식 기능을 열어 두지 않아서, 붙여넣기만 손으로 해요.
1. 글 폴더(예: `blog/posts/2026-11-23-kakao-order/`)의 **`naver.html`** 을 열어요.
2. 노란 상자 안내대로 제목 · 본문 복사 → 네이버 블로그 글쓰기에 붙여넣기
3. 그림 자리에 같은 폴더의 `card-1.jpg ~ card-3.jpg` 를 끌어다 놓기 (실제 화면 사진을 더 넣으면 더 좋아요: `landing-site/img/`)
4. 태그 붙여넣기 → **월요일 오전 7~9시**에 발행
- 네이버 팁: 글마다 **우리 회사 이야기 한 줄**(예: "저희 배차실은 오전 7시에 가장 바빠요")을 손으로 더하면 검색 품질 점수가 올라가요.
- 카드 이미지 3장은 **인스타그램 · 카카오톡 채널 · 밴드**에 그대로 올려도 돼요(1080×1080).

## 5. 매주 자동 블로그 (Gemini + GitHub Actions)

**매주 월요일 아침 7시 13분**에 저절로 돌아가요.

1. 이번 주 글이 없으면 `blog/calendar.json`의 다음 주제(24개 준비됨, 약 5개월 치)로 **Gemini가 글을 써요**. `brand/facts.md`의 사실만 쓰도록 되어 있어요.
2. 카드 이미지 3장 · 네이버용 `naver.html` · 홈페이지 블로그 페이지 · RSS · sitemap 을 만들어요.
3. **"블로그: 제목" PR**을 열어요 → GitHub 앱 알림 → 글을 읽어 보고 **Merge** 누르면 홈페이지에 올라가요. 그다음 `naver.html` 로 네이버에도 붙여넣기.

**처음 한 번만 설정 (5분)**
1. https://aistudio.google.com/apikey 에서 Gemini API 키 만들기(무료 사용량으로 충분)
2. GitHub 저장소 → Settings → Secrets and variables → Actions → **New repository secret** → 이름 `GEMINI_API_KEY`, 값에 키 붙여넣기
3. Settings → Actions → General → 맨 아래 **"Allow GitHub Actions to create and approve pull requests"** 체크 → Save
4. (확인) Actions 탭 → "매주 자동 블로그" → **Run workflow** 로 바로 한 번 돌려 볼 수 있어요.

**검토 없이 바로 올리고 싶으면**: Settings → Secrets and variables → Actions → **Variables** 탭 → `BLOG_AUTO_PUBLISH` = `true`. (처음 한두 달은 PR로 읽어 보는 걸 추천해요. AI가 화면에 없는 기능을 쓰는 경우가 가끔 있어요.)

**주제 바꾸기**: `blog/calendar.json` 에 한 줄 추가 — `{"slug":"영문-주소","title":"주제","keywords":"검색 키워드","angle":"관점","img":"real-board.jpg"}`

**직접 쓴 글 끼워 넣기**: `blog/posts/날짜-주제/` 폴더에 `post.md` + `cards.json` 을 넣으면(기존 글 복사해서 고치기) 그 주에는 자동 글을 쓰지 않고 그 글을 올려요.

## 7. 영상 다시 만들기 · 고치기

```bash
cd marketing/video
# 나레이션 글 고치기: narration.json 수정 → 음성 다시 만들기(바뀐 줄만)
GEMINI_API_KEY=키 python3 tools/tts.py
# 화면 고치기: scenes/shorts-1.html 등 수정 → 브라우저로 열면 미리보기, ?t=12 는 12초 장면
node render.mjs shorts-1            # out/shorts-1.mp4 (Playwright · ffmpeg 필요)
node render.mjs trailer --still 40  # 40초 장면만 png로
node tools/thumbs.mjs               # 썸네일
```
- 화면 영상 · 사진은 `landing-site/video`, `landing-site/img` 의 실제 프로그램 화면(가상 데이터)을 써요. 새로 찍으려면 `docs/landing-capture/README.md`.
- 배경음악은 직접 합성한 음악이라 저작권 걱정이 없어요(`tools/music.py`). 유튜브 오디오 보관함 음악으로 바꿔도 돼요.
- 나레이션 목소리는 Gemini TTS(숏츠 `Puck`, 예고편 `Charon`)예요. 바꾸려면 `narration.json` 의 `voice`.
